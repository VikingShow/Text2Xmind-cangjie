* [IllegalArgumentException](core_package_exceptions.html#class-illegalargumentexception) \- 如果找不到对应首位字节码，即指定字节所在位置的字节不符合 UTF\-8 编码，抛出异常。

* arr: [Array](core_package_structs.html#struct-arrayt)\<[UInt8](core_package_intrinsics.html#uint8)\> \- 待获取字符的字节数组。
* index: [Int64](core_package_intrinsics.html#int64) \- 指定字符的索引。


返回值：


* [Int64](core_package_intrinsics.html#int64) \- 字符的字节码长度，例如中文是三个字节码长度。


异常：


* [IllegalArgumentException](core_package_exceptions.html#class-illegalargumentexception) \- 如果索引位置的字节码不符合首位字节码规则，会抛出异常。
