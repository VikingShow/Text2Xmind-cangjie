功能：判断当前 [TypeInfo](reflect_package_classes.html#class-typeinfo) 实例对应的类型是否是参数中指定的 [TypeInfo](reflect_package_classes.html#class-typeinfo) 实例表示的类型的子类型。



> **注意：**
> 
> 
> 由于目前所有 `struct` 类型均无法获得其实现的 `interface` 类型，所以在做 `struct` 是否为某 `interface` 的子类型的判断时总是返回 `false` 。

* supertype: [TypeInfo](reflect_package_classes.html#class-typeinfo) \- 目标类型的类型信息。


返回值：


* [Bool](../../core/core_package_api/core_package_intrinsics.html#bool) \- 如果该 [TypeInfo](reflect_package_classes.html#class-typeinfo) 对应的类型是 `supertype` 所对应的类型的子类型则返回 `true`，否则返回 `false`。
